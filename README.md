# NETHERBORN Launcher

Launcher personalizado para o modpack privado NETHERBORN-2.

## Minecraft

- Minecraft Java Edition 1.21.1
- Fabric Loader 0.19.3
- Modpack privado
- Windows

## Objetivo

O NETHERBORN Launcher foi desenvolvido para simplificar a instalação e
inicialização do modpack NETHERBORN-2 para usuários autorizados.

O launcher utiliza a autenticação oficial da Microsoft para contas
Minecraft Java Edition.

## Privacidade

O aplicativo não solicita nem armazena senhas da conta Microsoft.
